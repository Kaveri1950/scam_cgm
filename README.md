# A Systematic Comparison of Analytical Models (SCAM) of the CGM
A common plateform to access different analytical CGM models.

scam_cgm

A Python package for analyzing and modeling the circumgalactic medium (CGM). This module provides tools and interfaces for working with CGM data in an astrophysical context.

Installation

You can install the package directly from GitHub using pip:

pip install git+https://github.com/Kaveri1950/scam_cgm.git

Alternatively, to install in editable mode (for development):

git clone https://github.com/Kaveri1950/scam_cgm.git
cd scam_cgm
pip install -e .

Usage

After installation, you can import and use scam_cgm in your Python scripts:

from scam_cgm import function_name  # replace with actual function names

Example:

from scam_cgm import HaloPotential as Halo

Requirements

You can also manually install them from the requirements.txt file if needed:

pip install -r requirements.txt
